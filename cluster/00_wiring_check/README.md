# 00_wiring_check

Wiring check

Pushes random tensors through every real code path - every ablation branch set, weight save/rebuild, Stage 1 pretraining and encoder transfer - for one tiny epoch each. Produces **no results**, only PASS/FAIL. Run it first on every new image: it is the only proof that the model builds under this image's Keras version.

- Expected time: under 5 min on a GPU
- Needs first: nothing
- Equivalent command on the M4 or any machine:

```bash
python train/run_pipeline.py --feature-store data/interim --task ovid --stages 00
```
